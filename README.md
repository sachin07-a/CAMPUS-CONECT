# 🎓 CampusConnect

> **"Your Campus. Your Community. Your Knowledge."**

An all-in-one, modern digital campus platform built for university students, faculty, clubs, and administrators. CampusConnect bridges the gap between academic resource libraries (Notion / Google Classroom), official digital notice boards, student organizations, hackathons, moderated community Q&A, and campus career drives.

---

## ✨ Key Features

- **🏠 Daily Student Dashboard**: Personalized academic feed tailored to branch (e.g. CSE) and semester (e.g. Sem 3) with urgent notice ticker and quick action shortcuts.
- **📚 5-Level Engineering Notes Hierarchy**:
  $$\text{Branch} \longrightarrow \text{Semester (1–8)} \longrightarrow \text{Subject} \longrightarrow \text{Unit (1–5)} \longrightarrow \text{Topic}$$
  Includes an interactive embedded document previewer with zoom and page navigation, 5-star ratings, download counters, and a 4-step note upload wizard.
- **📢 Official Notice Board**: Color-coded categorization (Exams, Scholarships, Placements, Department) with priority indicators and audience targeting.
- **🎟️ Events & Hackathons**: Event discovery with schedules, speaker lineups, and 1-click registration generating digital entry passes.
- **👥 Clubs & Societies**: Society profiles with coordinators, member tracking, and follow/join toggles.
- **💬 Moderated Student Community**: Subject Q&A with verified solutions and interactive live-voting campus polls.
- **💼 Placements & Internships**: Eligibility filters (CGPA, Branch), stipend/CTC packages, and 1-click applications.
- **🛡️ University Admin Control Center**: Analytics charts, user directory, flagged content resolution, and a live **Note Moderation Queue** to approve or request changes on student-submitted materials.
- **🔍 Global Search (`Ctrl+K` / `⌘K`)**: Instant categorized search across all collections.
- **🎨 Brand & Dark Mode**: Exact CampusConnect color palette (Royal Blue `#243BDB`, Indigo `#4338CA`, Purple `#7C3AED`, etc.) with high-contrast Dark Mode (`#0B1020`).

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, PostCSS, Custom Design System
- **Icons**: Lucide React
- **Architecture**: Modular Component-Driven Design, Reactive Store with Persistence

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
